// HOW IT WORKS

三層式智慧辨識流程

從影像擷取到違規通報，全程自動化處理，平均反應時間小於 1.2 秒。

01
📷
INPUT 資料蒐集
多路攝影機串流擷取公共區域影像，搭配 MQ-135 空氣品質感測器持續監測環境數據，雙管道資料並行輸入。
WEBCAM MQ-135 RTSP IoT
02
🤖
AI 辨識層
YOLOv8 進行物件偵測（人物、香菸），MediaPipe 分析手部與臉部關鍵點，多模態融合判斷消除誤報。
YOLOv8 MediaPipe Fusion Edge AI
03
🚨
OUTPUT 預警管理
即時廣播警示、自動臉部打碼後傳送後端、管理平台記錄完整違規時間軸，支援事後影像回放。
ALERT BLUR Dashboard Analytics

// FEATURES

系統核心功能

🎯
多模態融合判斷
影像、行為姿態、氣體感測器三路資料並行分析，相互驗證降低誤判率，準確率較單一影像方案提升約 40%。
⚡
即時預警廣播
偵測到吸菸行為後 1.2 秒內觸發廣播警示，主動嚇阻違規行為，無需人工介入。
🔒
隱私保護打碼
非違規者自動臉部模糊處理，僅保留違規畫面傳送後端，符合個人資料保護法規要求。
📊
數據分析後台
違規紀錄查詢、熱點分析、時段趨勢統計，輔助校方優化巡查策略與健康教育資源分配。
